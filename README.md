**Introduction**

The Weather Dashboard is a mobile application designed to display real-time weather metrics, hourly breakdowns, and multi-day forecasts. Users can easily switch between different South African cities (Johannesburg, Cape Town, and Durban) to view current temperatures, conditions, humidity, wind speed, visibility, UV index, and sunrise/sunset times.

**Development Environment**

The program was developed using the following: 

- Expo: tool used to manage and build the project  

- React Native: The framework used to build the mobile app 

- TypeScript: The language used to code the mobile app 

- Institutional VM: The virtual computer provided by Emeris used to code the project 

- BlueStacks 5: The emulator used to run the program 

- Expo Go: The app inside the emulator used to test the program

**Testing**

I tested my program using Expo Go through BlueStacks 5 which served as my emulator.   

When testing the app I: 

- Switched between the different cities  

- Checked that the data (temperature, humidity, wind speed, pressure, visibility and IV index changed when the city was changed 

- Confirmed that the 24 hour forecast worked 

- Confirmed that the 5 day forecast worked 

- Confirmed that the sunrise, sunset, moonrise, moonset and moonphase displays worked
